# Construção de Software para Web

Repositório destinado ao armazenamento dos conteúdos, exemplos e atividades desenvolvidas durante a disciplina de Construção de Software para Web.

## Conteúdos abordados

- HTML
- CSS
- JavaScript
- Estruturação de páginas web
- Estilização de páginas
- Manipulação de elementos
- Organização de projetos front-end

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Controle de Versão

O desenvolvimento das atividades foi acompanhado utilizando Git e GitHub para versionamento e gerenciamento do código.

## Objetivo

Registrar minha evolução prática na disciplina, reunindo os exercícios e exemplos desenvolvidos ao longo do semestre.
